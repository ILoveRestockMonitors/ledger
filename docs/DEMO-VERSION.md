# Demo version

Choose **Demo version** in the sidebar (on phones, open **More** first). Ledger opens fictional finances with a visible Demo label. Choose **Return to my Ledger** to return to your records. Reloading the demo keeps it active; the `?demo=1` URL is specific to that tab. The existing owner sign-in remains required. This feature is a presentation mode, not a public sharing link or a privacy lock on other browser tabs.

Explore Home, Transactions, Subscriptions, Budgets, Goals, Accounts, Reports, Personal, Business and Your future. Search, category/date filters, report years, projection scenarios and sample CSV exports use the separate dataset. Appearance controls remain usable. Financial records are read-only, and bank/merchant actions are disabled by the backend. The old Settings sample-loading button now opens this mode instead of adding records to the current workspace.

The synthetic data rolls forward with the calendar and is regenerated in temporary storage after a server restart or date change. It does not read or modify the live financial database or saved financial configuration. Demo appearance preferences are stored separately for the browser session.

Implementation: `backend/demo_preview.py`, the preview boundary in `backend/server.py`, request-local storage in `backend/db.py`, and `web/demo.js`/`web/demo.css`. Deploy these alongside the updated index, API client, export function and Settings wiring; frontend-only deployment is insufficient. Existing data volumes and authentication must remain intact. No data migration or seed command is required.
