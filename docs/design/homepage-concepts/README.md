# Home page concepts

Ten alternative designs for Ledger's Home (Overview) page, drawn as Design
Component artboards and published as one pan/zoom canvas.

They run from the most reduced version that still works (`Main.dc.html`) to the
most elaborate (`Cartography.dc.html`). Every concept shows the same September
2026 data so they compare directly; `BRIEF.md` is the single source for those
figures and for the tokens lifted out of `web/styles.css`, `web/paper.css` and
`web/comfort.css`.

| # | File | Direction |
|---|------|-----------|
| 01 | `Main.dc.html` | Plain — one number on paper, no chrome at all |
| 02 | `Receipt.dc.html` | The month as a printed till slip |
| 03 | `Ruled.dc.html` | The accountant's ruled book; no cards |
| 04 | `Swiss.dc.html` | International Typographic Style, visible grid |
| 05 | `Calm.dc.html` | Today's Ledger, refined — the buildable one |
| 06 | `Almanac.dc.html` | A private monthly broadsheet |
| 07 | `Terminal.dc.html` | Dark, dense, keyboard-first |
| 08 | `Horizon.dc.html` | Data-forward; the month as a horizon line |
| 09 | `Atelier.dc.html` | Maximalist, art-directed, layered paper |
| 10 | `Cartography.dc.html` | The month as a surveyor's plate |

`canvas.json` is the canvas layout and is generated by `mkcanvas.mjs`, which
also prints the `--artboard` arguments for seeding. The seeded `.html` canvas is
a build output and is not committed.
